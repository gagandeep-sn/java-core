# Simple Array Sorting

## Category

Arrays

## Difficulty

Easy

## Concepts

* Arrays
* Sorting

## Code Logic

1. An array of integers named 'numbers' is declared and initialized with some unsorted values.
2. The Arrays.sort() method is called on the 'numbers' array, which sorts the array in ascending order.
3. The Arrays.toString() method is used to convert the sorted array into a string, which is then printed to the console.
4. The output is the sorted array, where the smallest number comes first and the largest number comes last.

## Time Complexity

O(n log n)

## Space Complexity

O(n)

## Interview Relevance

Low

## Topic Mastery

Beginner

## Explanation

This Java program sorts an array of integers in ascending order using the built-in Arrays.sort() method. It takes an array of unsorted integers as input, sorts them, and then prints the sorted array. The output is a sorted array where the smallest number comes first and the largest number comes last.
